# 一小时续验的结论

四比特模型有 3,840 个“沿方形一圈应当翻面”的条件。允许两张任意且独立的符号表。**失败数的最小值为 256，第二小值为 282。让修复张量的两种切割秩同时下降，最少也恰好需要 282 次失败。**

| 可实现构造 | 带起点失败数 | 两个残差矩阵的有理秩 |
|---|---:|---:|
| 任意最优解 | 256 | (256,256) |
| 在最优商构造的行表翻转 (0,0) | 282 | (255,254) |
| 在同一构造的行表翻转 (0,0)，列表翻转 (0,1) | 304 | (253,253) |

在第一行，全部 256 个失败落在唯一方向。更强的是，归一化残差只需重标两条张量腿并给边界乘正负号，就能变回原来的完整交叉。因此最少失败的构造把一个完整交叉藏进了稀疏残差。这个结论解释了为何单纯优化失败比例不能给出更便宜的精确计数算法。[最优解、计数与边界符号](RigidityKernel.md)

第二行的构造容易直接核对。困难在于排除 257 至 281 之间的全部值。证明使用原有矛盾证书在 20,160 个换基下的像，以及同一个有限傅里叶二阶矩的上下界。整数证书和另一份独立计算均排除了这些中间值。第三行给出允许两张表一起变化时同时降低三秩的上界。[全局次重量证明](SecondWeight.md) · [有限轨道的概率计算](FourGapOrbits.md)

如果固定一张能延拓为最优解的表，则要求两种秩都至少下降 j，精确代价为 256+26j，其中 0≤j≤16。再往下降在此固定表的模型中不可能。对应 j=3 的代价是 334，一般双表已能做到 304。一般模型的第二重量已定；是否还有完全不同的 282 解，以及两边都降 2 或 3 秩的精确阈值，仍然开放。[固定一张表的完整曲线](LockedRankCurve.md)

五比特一般双表的最少失败数介于 2,342 和 3,072 之间，分母为 31,744。若限定其中一张表属于文中精确刻画的 404 维二元函数空间，另一张表仍可任意选择，最少恰为 3,072，即 3/31。该空间包含所有总次数至多三的布尔多项式。[五位非受限下界](FiveCollisions.md) · [结构化子类及验证范围](FiveRowAffine.md)

对 ETH 论文真正使用的精确交叉张量，使用 Breuer 见证的一种三项分组。把 t 个三比特块合并为 2t+1 组，各组的双切割整数分离项数之积至多为 1521^t；中心组的任意整数分离表示又至少要 1521^t/(2t+1)²。因此 1521 是这个指定分组方案的精确渐近底数。它改进了上游附录 H 八平方构造的 1792 基准；附录 B 的分级算子给出更好的整体参数。数学上这是一项局部构造改进，未给出更强的普通 SAT 时间界。[算法接口与秩证明](RankTrade.md) · [上游附录 A、B、H](https://github.com/anthropics/formal-math/blob/16a5ce41304fcdaea4e0be7c132e1c361dc26da5/eth/paper.pdf)

**验证层次。** Lean 内核验证了最优解的方向、精确数目、最优残差的局部等价、固定另一张表时的间隙、282 构造及两切的零行、五位结构化表的下界和具体达到例，以及三位分组的因子化和上下界。一般双表的 282 全局阈值目前是数学证明加精确的有限计算。五位无约束下界与固定表的完整秩曲线各有书面推导和可复算检查。这里没有对 282 或 1521 的文献优先权作断言，也没有得到 P vs NP 或其相对于 Lean 独立性的结论。

**与 Arth Singh 下界的交叉核验。** 允许两种切割混合时，最优四位残差至少要 22 个秩一项；具体的 282 和 304 构造也保留至少三个完整的 16 维单位矩阵切片，由原文三切片证明同样至少要 22 项。[定义、归约与验证范围](Naslund.md)
