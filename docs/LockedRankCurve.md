# 固定一张最优表时，降低残差秩的精确代价

起点是任意一对达到 256 次带锚失败的双表。固定其中的列表，允许行表的 256 个符号任意变化。问的是让两个 256 阶残差矩阵的秩都**至少**下降 j 所需的最少失败数。秩取在有理数上。结论为

    0 ≤ j ≤ 16 时，最少恰为 256 + 26j；
    j > 16 时，在此固定表的模型中无法达到。

交换行、列两表，结论对称。证明利用了对于每个异或键，残差块与无符号失败邻接矩阵只差可逆的对角符号与一个公共非零倍数。[分块恒等式与形式化范围](RankTrade.md)

**一个键上的图。** 令 h 是起始最优解的唯一失败方向。在行切的每个键 s=x+y 上，失败的位置构成 16 个顶点间由 x↔x+h 给出的完美匹配 M。改变该键下一个顶点集 T 的行符号，恰好将割 (T,Tᶜ) 上的失败/成功对换。设 |T|=k，匹配中跨割的无向边数为 m。额外几何失败数是 k(16−k)−2m，两倍即带锚的增量。m≤min(k,16−k)，故每个非恒定改动至少新增 26 次带锚失败。

**开关一个割后还有多少秩？** 记 d 是沿 T 取负、其余取正的 16 维向量，D 是其对角矩阵，1 是全一列向量。改动后失败邻接矩阵为

    D M D + (11ᵀ − ddᵀ)/2。

第一项是自己的逆。写 U=(1,d)、C=diag(1/2,−1/2)，解零空间方程可知该矩阵的零度等于 I₂+C Uᵀ(DMD)U 的零度。这个等式即使 k=0 或 16、U 有相关列也成立：由大方程的解 z 取小方程的未知量 C Uᵀz，反向取 z=−(DMD)U w。三个内积分别为 16−4m、16−2k、16，故小矩阵是

    [     9−2m     8−k ]
    [   −(8−k)     −7  ]。

它的行列式是 (8−k)²+14m−63。若为零，则 8−k 被 7 整除。候选 k 为 1、8、15，其中 k=8 会要求 m=9/2；k=1,15 各使 m=1，确实产生一维零空间。因此只有在一个键上翻转一个符号或其补集才会降低该块的秩，且只降低 1。16 个行块直和，行秩至少为 240。要下降 j，至少 j 个键须各自付出 26 次失败。

**同时达到两侧要求。** 任取 j 个不同的键 s，每个键只翻转行表的格子 (0,s)。行切恰损失 j 秩，失败数为 256+26j。看列切的键 t=x+u，其原图仍为同一方向的完美匹配。一处 (0,s) 改动只可能改变该块中以 0 为端点的边。当 t=s+h 时它移除了匹配边 {0,h}。对 j 个不同的 s 相应有 j 个不同的列块。在每个这样的块中，顶点 h 一定孤立，因为其他改变只可能涉及以 0 为端点、对端不等于 h 的边。于是列秩也至少损失 j。

**允许同时改两张表会怎样。** 例如分别翻转行表的 (0,0) 与列表的 (0,1)。两次改动同时涉及一个原本成功的测试，因此最终有 304 次带起点失败，两个残差秩均为 253。固定一张表要同时降 3 秩则必须付出 334 次。这里的 304 为构造上界；一般双表同时降 2 或 3 秩的精确阈值尚未确定。

`python3 experiments/locked_rank_curve.py` 用有理数消元逐一检查 17 个可达点、单块的所有匹配类型，并列举相对于固定起始格的 511 种双格改动。上文的一般秩证明是纸笔证明。Lean 的 `LockedGap` 模块核验了单块计数、总计数间隙、282 的单格构造及两个切割中的零行。
